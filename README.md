# Observatório do Biometano

Site estático do Observatório do Biometano: dados abertos sobre o biometano em Portugal continental, projeto a projeto, com a fonte pública de cada valor.

Endereço: https://rralex96.github.io/observatorio-biometano/

Este repositório contém só o site publicado; é gerado automaticamente e não deve ser editado à mão. Para corrigir um dado, abra uma questão (Issues) com a evidência: um documento público, um número de registo ou uma ligação.
